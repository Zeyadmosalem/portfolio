How I test

Every layer, on every push

  1. Database

    pgTAP tests prove each role can read and write exactly the rows it should, and nothing more.

  2. Security

    Red-team suites try to escalate privileges and read hidden data. If they succeed, the build fails.

  3. Server and edge

    Edge Functions and Workers are tested for grading logic, session checks, throttling and security headers.

  4. Interface

    Vitest and Testing Library cover components and flows the way a person actually uses them.

  5. CI gate

    GitHub Actions runs everything, enforces coverage, and blocks the deploy when the schema isn't current.
