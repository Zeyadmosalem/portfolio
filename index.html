Selected work

Apps I built, from database to deploy

The first two are client projects in private repositories, so they link to a walkthrough instead of the code.

  1. 01

    Accounting & e-invoicing system Client project

    A back office and client portal for an Egyptian accounting and tax firm.

    Accountants keep the general ledger, financial statements, VAT returns, payroll and company formation work; the firm's clients sign in to issue e-invoices and track their filings. It integrates with the Egyptian Tax Authority (ETA) to submit, sync, cancel and reject e-invoices and receipts, and builds VAT sheets in ETA's official format. Per-department staff permissions, two-factor sign-in and a full audit log. About 600 tests in CI; co-developed with one other engineer.

    Python · Django · PostgreSQL · ETA e-invoicing API · Arabic RTL interface

    Ask for a walkthrough →
  2. 02

    Financial statements pipeline Client project

    Turns listed companies' annual reports into data a financial platform can import.

    It finds and downloads companies' annual reports, locates the balance sheet, income statement and cash flow pages, reads them from the PDF text layer with an OCR fallback for scans (Arabic-Indic digits included), maps every printed line to the platform's codes, and checks the totals add up before anything is staged for human review. Built to the client's brief so it moves into their backend without a rewrite. About 100 tests, including a hand-checked gold set of real filings.

    Python · Pydantic · pdfplumber · Tesseract OCR · PostgreSQL

    Ask for a walkthrough →
  3. 03

    NC Spark

    A role-based training platform with four portals and server-side grading.

    Trainee, trainer, supervisor and admin portals with seven activity types, all authored in the browser. Quizzes are graded in Edge Functions against an answer key no browser role can read, and column grants, row-level security and triggers block privilege escalation. A Cloudflare Worker gates the site, throttles sign-ins and sets security headers. 1,828 tests at 91% coverage, including red-team suites.

    React 19 · Vite · Supabase / Postgres 17 · Edge Functions · TanStack Query · Cloudflare Workers · Vitest

How I build

Every layer, end to end

  1. Requirements

    I talk to the people who will use the app and turn what they need into a data model and a plan.

  2. Database

    Postgres schema, migrations and row-level security, so each role reads and writes exactly the rows it should.

  3. Server and integrations

    Sensitive logic stays on the server, in Django, Edge Functions or Cloudflare Workers, along with integrations like the ETA e-invoicing API.

  4. Data

    Python pipelines that read Arabic and English PDFs, map them to a clean schema and check the numbers before anything is imported.

  5. Interface

    React and TypeScript interfaces in Arabic and English, right-to-left included, that work offline as installable PWAs.

  6. Test and ship

    Automated tests at every layer run in GitHub Actions, and the deploy is blocked until everything passes.
