    NC Spark

    A role-based training platform with four portals and server-side grading.

How I build

Every layer, end to end

  1. Requirements

    I talk to the people who will use the app and turn what they need into a data model and a plan.

  2. Database

    Postgres schema, migrations and row-level security, so each role reads and writes exactly the rows it should.

  3. Server and edge

    Sensitive logic lives in Edge Functions and Cloudflare Workers: grading, session checks, throttling and security headers.

  4. Interface

    React and TypeScript interfaces in Arabic and English, right-to-left included, that work offline as installable PWAs.

  5. Test and ship

    Automated tests at every layer run in GitHub Actions, and the deploy is blocked until everything passes.
