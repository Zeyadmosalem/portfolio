About

Quality you can prove, not just hope for.

I write automated tests that catch real bugs, from Postgres security policies up to the browser, and I run them in CI so nothing broken ships.

I test access control the way an attacker would: red-team suites that try to escalate privileges or read data a role shouldn't see, and fail the build if they succeed. Across my projects, that's more than 2,900 automated tests running on every push.

I also build the apps I test, in React, TypeScript and Supabase, so I can read the code, find the root cause and write a bug report a developer can act on. I use AI coding tools like Claude Code to move faster, while owning the test strategy and the quality.

Every layer, every push.
